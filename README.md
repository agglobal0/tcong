# The Church of New Generation — Full-Stack Website & Admin CMS

A modern, production-ready website and Content Management System (CMS) built for **The Church of New Generation**.

---

## Features

- **Public Website (SPA)**:
  - Hero section with welcoming dynamic content
  - Church background, mission, vision, values & statement of faith
  - Interactive event management (upcoming vs past events, registration, maps)
  - Sermons media center with YouTube video embeds and thumbnail support
  - Prayer Request System (with anonymity options, categories, and consent validation)
  - Donation system architecture (Razorpay integration ready, preset & custom amounts, strict non-credential storage)
  - Lightbox photo gallery, testimonials, contact form, and newsletter subscription
  - Responsive design optimized for mobile, tablet, and desktop

- **Admin Content Management System (CMS)**:
  - Role-Based Access Control (RBAC): Super Admin, Content Manager, Event Manager, Prayer Manager, Finance Manager
  - Dashboard analytics with real-time counters, stats, and Chart.js visualizations
  - Prayer request workflow tracking (`NEW` -> `ASSIGNED` -> `IN_PRAYER` -> `PRAYED` -> `CLOSED`) with internal notes and team member assignment
  - Rich text blog, sermon, event, and photo album management
  - Contact message inbox and subscriber export
  - Media library with file upload & MIME validation
  - Global site settings editor (church name, tagline, service times, social URLs, SEO meta tags)
  - Activity audit logging for security and compliance

---

## Technology Stack

- **Frontend**: HTML5, CSS3 (Custom Brand Tokens + CSS Variables), Modern JavaScript, Bootstrap 5, Font Awesome 6, Swiper.js, Chart.js
- **Backend**: Node.js, Express.js (REST API Architecture)
- **Database**: MySQL 8.0+ (Relational Design with Foreign Keys, Indexes, Migrations & Seeders)
- **Authentication**: JWT (JSON Web Tokens) with httpOnly cookies & bcryptjs password hashing
- **Security**: Parameterized SQL queries, XSS sanitization (`xss`), Rate limiting (`express-rate-limit`), Helmet headers, CORS policies
- **File Uploads**: Multer with MIME validation & upload directory mapping (Cloudinary/AWS S3 ready)
- **Payments**: Razorpay integration architecture (Order creation & HMAC SHA256 signature verification)

## Installation & Setup Guide

### 1. Prerequisites
- Node.js (v18+)
- MySQL Server (v8.0+)
- npm or yarn

### 2. Environment Configuration
Copy `.env.example` to `.env` inside the `server/` directory:

```bash
cd server
cp .env.example .env
```

Edit `.env` with your database credentials:
```env
PORT=5000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=tcong_db

JWT_SECRET=super_secret_jwt_key_change_in_production
ADMIN_EMAIL=admin@tcong.org
ADMIN_PASSWORD=Admin@123456
```

### 3. Database Migration & Seeding
Run the automated migration and seeder scripts to create tables and load demo content:

```bash
# Run database migrations (Creates all 30+ tables)
npm run migrate

# Run database seeders (Creates admin user, roles, permissions & initial content)
npm run seed
```

Default Admin Credentials generated by seeder:
- **Email**: `admin@tcong.org`
- **Password**: `Admin@123456`

### 4. Running the Application

```bash
# Start backend server with live reload (Nodemon)
npm run dev
```

Open your browser and navigate to:
- **Public Website**: `http://localhost:5000/`
- **Admin CMS Dashboard**: `http://localhost:5000/admin`
- **API Base Endpoint**: `http://localhost:5000/api`

## Payment Gateway Setup (Razorpay)

To activate live donations:
1. Sign up on [Razorpay Dashboard](https://dashboard.razorpay.com/).
2. Obtain your **Key ID** and **Key Secret**.
3. Add them to your `server/.env` file:
   ```env
   RAZORPAY_KEY_ID=rzp_live_xxxxxxxx
   RAZORPAY_KEY_SECRET=xxxxxxxxxxxxxxxx
   ```
4. The system will automatically use the Razorpay API for order creation and SHA256 signature verification.
5. **Security Guarantee**: Sensitive payment details (card numbers, CVV, UPI PINs) are never sent to or stored in MySQL.

## Deployment

1. **Production Environment**: Set `NODE_ENV=production` in `.env`.
2. **Reverse Proxy**: Configure Nginx or Apache as a reverse proxy for port `5000` with SSL (Let's Encrypt / Certbot).
3. **Process Manager**: Use PM2 to run the Node.js application in production:
   ```bash
   npm install -g pm2
   pm2 start server.js --name "tcong-server"
   ```
